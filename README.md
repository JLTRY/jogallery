## Requirements

Joomla 5.0+ 

## Features
The package includes a component and a 3 plugins
- component_jogallery : used to configure galleries of your images
- plugins/content/jogallery : a plugin that helps to include a gallery into your articles
- plugins/content/jodirectory : a plugin that helps to include a gallery as directory of images into your articles
- plugins/editors-xtd/jogallery : a plugin that adds an helper button in backend editor


This extension allows to add one of the galleries that have been configured based on the images/videos 
located in subfolders of the /images **Joomla** directory.
The galleries can be simply configured by selecting one of the folders. The images/videos are retrieved recursively.
The thumbs can be built automatically.
Once configured, the galleries can be shown in articles.
